Meow Meow Veterinary AI Front Desk

An event project exploring how an AI agent can connect a front-desk request with calendar scheduling and structured record-keeping through an n8n workflow.

n8n × GEMINIREQUEST → AI AGENT → CALENDAR + SHEETS

Project overview

Connecting an AI agent to useful tools.

The workflow was built around a veterinary front-desk scenario. A form submission enters an n8n workflow and is passed to an AI Agent configured with a Google Gemini chat model. The agent is connected to Google Calendar for appointment retrieval and creation, Google Sheets for appointment records, and memory for conversational context.

05 / CONTEXT

Agent memory

Provides a memory connection to the AI Agent for conversational context.

What I explored

From a prompt to a connected workflow.

This project helped me explore the structure of an AI-agent workflow: an input trigger, an agent powered by a language model, and connected tools that let the workflow interact with calendar and spreadsheet services. It was a hands-on introduction to n8n automation and tool-connected AI systems.

This case study describes the workflow components shown in the event project. It does not claim production deployment or independently verified live appointment handling.
