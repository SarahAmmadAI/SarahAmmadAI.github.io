Overview

Small surface, important fundamentals.

The project exposes two simple routes: one for a greeting and another for server status. Building a minimal API helped me practise how a client sends a request, how an Express route handles it, and how a server returns a predictable response.

Run locally

Try it on your machine.

Clone the repository and install its dependencies, then start the server using the command specified in the project README.

npm install · then node server.js · open localhost:3000 or localhost:3000/status.
